# E-Commerce Sales & Customer Intelligence Platform

## Overview

An end-to-end data analytics project analyzing an e-commerce retail dataset to understand sales performance, customer behavior, and product performance.

The project uses Excel, MySQL, Python, and Power BI to transform raw retail transaction data into business insights.

## Business Problem

The project analyzes e-commerce transaction data to identify sales trends, customer purchasing behavior, and product performance.

The objective is to use data analysis to answer practical business questions and support data-driven decision making.

## Objectives

- Analyze overall sales and revenue performance
- Identify important customer behavior patterns
- Analyze product performance
- Identify sales trends over time
- Perform customer segmentation using RFM analysis
- Build an interactive Power BI dashboard
- Present business insights and recommendations

## Dataset

Dataset: Online Retail Dataset

Source: UCI Machine Learning Repository

The project uses a cleaned 20K-row version of the Online Retail dataset.
